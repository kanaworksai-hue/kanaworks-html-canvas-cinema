# HTML in Canvas Cloth Cinema

An interactive Three.js demo that renders HTML, images, or video onto a wind-driven cloth screen.

## Features

- Live HTML texture capture for the curtain surface
- Image and video upload as the screen texture
- English, Chinese, and Japanese content
- Movable fan with coordinate, wind strength, and direction controls
- Draggable cloth interaction
- Night outdoor cinema mode with adjustable projector light and romantic moving stars
- KanaWorks_AI follow button

## Run Locally

```bash
bun install
bun run dev
```

Then open `http://127.0.0.1:5173/`.

The published version is static and runs directly from GitHub Pages.
